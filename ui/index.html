Eigene Keywords

Eigene Keywords benutzt du im Editor jedes Moduls, z. B. {streamer} in einem Text – sie stehen dort unter „Variablen → VentoView“. Ein Keyword kann ein fester Text sein oder laufend neu gelesen werden: aus einer Datei, einem PowerShell-Befehl oder einer Webadresse. Fest eingebaut sind {zeit}, {datum}, {wochentag} und {laufzeit}.

Beispiele zum Übernehmen

So bindest du eigene Daten ein

Text – feste Angaben wie dein Name, Discord oder deine PC-Teile. Ändert sich nur, wenn du ihn änderst.

Datei – der Inhalt einer Textdatei. Viele Stream-Tools (Musik-Player, Bots, Spendentools) können Infos in eine .txt-Datei schreiben. VentoView liest sie im eingestellten Abstand und zeigt immer den neuesten Stand.

Befehl – die Ausgabe eines PowerShell-Befehls. Damit kommst du an fast alles, was Windows weiß. Teste den Befehl zuerst in PowerShell: Was dort als Text herauskommt, wird der Wert. Langsame Befehle lieber selten ausführen (30–300 s).

Webadresse – die Antwort einer Adresse, z. B. eines Programms mit eingebautem Webserver oder einer API. Mit dem JSON-Pfad holst du ein einzelnes Feld heraus: data.title, items[0].name – oder du suchst im ganzen Baum: **[Text~Tctl].Value nimmt das erste Objekt, dessen „Text“ „Tctl“ enthält.

Beispiel CPU-Temperatur: Windows liefert sie meist nicht selbst. Installiere das kostenlose LibreHardwareMonitor, starte es (am besten als Administrator) und schalte unter Options → Remote Web Server → Run den Webserver ein. Dann das Beispiel „CPU-Temperatur“ übernehmen. Bei Intel-Prozessoren statt Tctl den Pfad **[Text~CPU Package].Value nehmen.

Im Overlay funktionieren eigene Keywords wie alle anderen – auch in Bedingungen: z. B. eine rote Textebene mit der Bedingung „cputemp größer als 80“.

Befehle laufen mit deinen Rechten auf diesem PC. Trag nur Befehle ein, die du verstehst – niemals welche, die dir jemand im Chat schickt.
