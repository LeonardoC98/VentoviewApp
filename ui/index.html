Eigene Keywords

Eigene Keywords benutzt du im Editor jedes Moduls, z. B. {streamer} in einem Text – sie stehen dort unter „Variablen → Ventoview“. Ein Keyword kann ein fester Text sein oder laufend neu gelesen werden: aus einer Datei, einem PowerShell-Befehl, einer Webadresse oder eigenem Python-Code. Fest eingebaut sind {zeit}, {datum}, {wochentag} und {laufzeit}.

Beispiele zum Übernehmen

So bindest du eigene Daten ein

Text – feste Angaben wie dein Name, Discord oder deine PC-Teile. Ändert sich nur, wenn du ihn änderst.

Datei – der Inhalt einer Textdatei. Viele Stream-Tools (Musik-Player, Bots, Spendentools) können Infos in eine .txt-Datei schreiben. Ventoview liest sie im eingestellten Abstand und zeigt immer den neuesten Stand.

Befehl – die Ausgabe eines PowerShell-Befehls. Damit kommst du an fast alles, was Windows weiß. Teste den Befehl zuerst in PowerShell: Was dort als Text herauskommt, wird der Wert. Langsame Befehle lieber selten ausführen (30–300 s).

Webadresse – die Antwort einer Adresse, z. B. eines Programms mit eingebautem Webserver oder einer API. Mit dem JSON-Pfad holst du ein einzelnes Feld heraus: data.title, items[0].name – oder du suchst im ganzen Baum: **[Text~Tctl].Value nimmt das erste Objekt, dessen „Text“ „Tctl“ enthält.

Python – eigener Code, der aus anderen Variablen neue macht. Alle Variablen stehen unter ihrem Namen bereit, Zahlen schon als Zahlen: test = 2 * ping ergibt bei 42 ms „84“. Den Wert setzt du mit dem Namen des Keywords (sonst zählt ergebnis = … oder was der Code mit print ausgibt). True/False werden zu „ja“/„nein“, ein Wörterbuch wie {"a": 1} zu eigenen Variablen ({test_a}). speicher merkt sich Werte zwischen den Läufen, z. B. speicher["n"] = speicher.get("n", 0) + 1. Fehler stehen rot in der Vorschau, mit Zeilennummer.

Sicherer Modus – Python-Keywords dürfen standardmäßig nur rechnen und mit Text arbeiten, dazu Module wie math, random, datetime, statistics, json und re. Gesperrt sind Dateien, Programme, Netzwerk und Python-Interna. „Voller Zugriff“ hebt das für ein Keyword auf – nur für eigenen Code, den du verstehst. Braucht Python 3 von python.org (Haken bei „Add to PATH“).

Beispiel CPU-Temperatur: Windows liefert sie meist nicht selbst. Installiere das kostenlose LibreHardwareMonitor, starte es (am besten als Administrator) und schalte unter Options → Remote Web Server → Run den Webserver ein. Dann das Beispiel „CPU-Temperatur“ übernehmen. Bei Intel-Prozessoren statt Tctl den Pfad **[Text~CPU Package].Value nehmen.

Im Overlay funktionieren eigene Keywords wie alle anderen – auch in Bedingungen: z. B. eine rote Textebene mit der Bedingung „cputemp größer als 80“.

Befehle und Python-Code mit vollem Zugriff laufen mit deinen Rechten auf diesem PC. Trag nur ein, was du verstehst – niemals Code, den dir jemand im Chat schickt.

Auf eigene Verantwortung: Programme anderer Hersteller (z. B. LibreHardwareMonitor – offiziell nur auf github.com/LibreHardwareMonitor) installierst du selbst. Ventoview haftet nicht für Schäden, Datenverlust oder Schadsoftware.

Vorlagen exportieren

Wähle Vorlagen aus – eigene Bilder, Videos und Töne darin packt Ventoview mit ein.

Importieren

So teilst du Vorlagen

1. Exportieren: Vorlagen anhaken, „Exportieren“. Ventoview legt einen Ordner in Dokumente\Ventoview\Teilen an und zeigt ihn dir.

2. Weitergeben: Den ganzen Ordner verschicken – am einfachsten als ZIP (Rechtsklick → „Senden an“ → „ZIP-komprimierter Ordner“). Wichtig ist der ganze Ordner, nicht nur die .json-Datei, sonst fehlen Bilder und Töne.

3. Einsetzen: Wer ihn bekommt, entpackt ihn und legt den Ordner in seinen Teilen-Ordner (Dokumente → Ventoview → Teilen, Knopf „Teilen-Ordner öffnen“). Er erscheint dann oben in der Liste – auf „Importieren“ klicken. Liegt er woanders: „Anderen Ordner wählen“.

Vorhandene Vorlagen werden nie überschrieben. Module, die eine Vorlage braucht, müssen in der App aktiv sein.

Erweiterungen Erweitern die App auf diesem PC, z. B. um Tastenkürzel. Die .vvext-Datei gibt es nach dem Kauf auf der Webseite.
Komplette Sicherung Alle App-Daten als eine .vview-Datei: Designs, eigene Medien, Modul-Einstellungen, Keywords, Home und Einstellungen. Konto- und Twitch-Verbindung bleiben auf diesem PC.
